# Okal Project Wiki

**One local personal assistant for mail, planning, social content and freelance opportunities.**

## Current direction

Start with the [Personal Assistant Plan](Personal-Assistant-Plan).
The repository is transitioning to one small code-first center with a shared API
for desktop, mobile and later voice. This is a proposal, not a deployed system.

The first implementation is a small authenticated inbox and startup/recovery
foundation, followed by a real read-only Gmail digest. No parallel agent projects.

## Historical context

Earlier designs retain useful security and reliability requirements but are not
a second active feature backlog. Broad coding/research showcases, memory fabrics
and voice-first delivery are out of scope or deferred under the proposed reset.
Accepted decisions are superseded only through reviewed ADR changes.
